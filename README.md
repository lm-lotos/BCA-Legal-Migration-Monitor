# BCA Legal & Migration Monitor

Небольшой рабочий монитор для ежедневной проверки изменений и новостей по миграции, пребыванию, Blue Card, Fachkräfte, убежищу и связанным темам в Германии.

## Как работает

Главная страница показывает одну общую свежую подборку из официальных источников и немецких СМИ. В рабочую ленту попадают только материалы с определяемой датой публикации за последние 48 часов. Сначала показываются самые новые.

Кнопка **«Проверить сейчас»** запускает новый обход источников. Найденные публикации сохраняются в локальной SQLite-базе. Поэтому материал, который был найден при предыдущей проверке, не исчезает из ленты только потому, что источник не вернул его при следующем запросе. Он остаётся в свежей подборке, пока его реальная дата публикации находится внутри 48-часового окна.

Для каждой публикации база хранит также время первого и последнего обнаружения. История остаётся внутри базы и сейчас не перегружает основной интерфейс отдельным архивом.

Во вкладке **«Источники»** можно увидеть подключённые источники и состояние последней проверки. Это позволяет отличить ситуацию «свежих материалов нет» от технической ошибки при обращении к источнику.

## Источники

Официальный блок включает Gesetze im Internet / Recht.Bund, Bundesagentur für Arbeit, BA Weisungen, BAMF, LEA Berlin, Bundestag и федеральные источники, включая Bundesrat, BMI, BMAS и Bundesregierung.

Медийный блок включает общегерманские и региональные немецкие СМИ: Tagesschau, ZDFheute, Deutschlandfunk, DW, SPIEGEL, ZEIT, Süddeutsche Zeitung, FAZ, Handelsblatt, WELT, Tagesspiegel, а также WDR, NDR, BR24, SWR, MDR, rbb24, hr, Radio Bremen и SR.

Монитор показывает заголовок, краткую информацию и ссылку на оригинальный материал. Полный текст остаётся на сайте первоисточника.

## Поиск

Поиск работает по текущей свежей подборке за последние 48 часов. Старые публикации из внутренней истории в результаты рабочего поиска не подмешиваются.

## Перевод

Интерфейс позволяет переводить найденные материалы через DeepL API. Для перевода пользователь вводит собственный API key. Без ключа монитор продолжает работать, просто без функции перевода.

## Запуск локально

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Важно

Дата первого обнаружения материала монитором и дата публикации — разные вещи. В 48-часовую ленту материал допускается по дате публикации, а не по времени, когда монитор впервые увидел ссылку.

Система предназначена для мониторинга и быстрого перехода к первоисточникам. При принятии юридических решений следует проверять оригинальную официальную публикацию.
