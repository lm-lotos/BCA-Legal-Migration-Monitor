# BCA Legal & Migration Monitor

**BCA Legal & Migration Monitor** — Streamlit-приложение для быстрого мониторинга публикаций, которые могут быть важны для работы BCA в сфере миграции, трудоустройства и законодательства Германии.

Монитор объединяет официальные немецкие источники и СМИ, автоматически оценивает релевантность материалов и позволяет быстро перейти от общей картины к конкретной публикации.

🌐 **Онлайн-приложение:** https://bca-legal-migration-monitor.streamlit.app/

---

## Как пользоваться

В верхней части приложения находятся четыре основных раздела:

- **Публикации** — актуальные материалы, прошедшие BCA-фильтр.
- **Архив** — поиск по сохранённым публикациям.
- **Поиск** — тематический и свободный поиск.
- **Источники** — статистика и просмотр материалов по конкретным источникам.

Для чтения полной публикации нажмите **«Открыть оригинал»**.

## Публикации

Материалы можно фильтровать по конкретному источнику или по степени релевантности для BCA:

- 🟢 **высокая** — непосредственно связана с основными темами BCA;
- 🟡 **средняя** — может быть полезна в работе или требует внимания;
- 🔴 **низкая** — прошла тематический фильтр, но имеет меньшую практическую значимость.

В каждой ячейке источника сначала показано общее количество материалов, затем распределение по светофору.

Пример: `ВСЕ - 67:  🟢 1  🟡 47  🔴 19`

Публикации выводятся порциями по 20, чтобы интерфейс оставался удобным.

## Источники

### Официальные

В проект включены, в частности:

- Gesetze im Internet;
- Bundesagentur für Arbeit / BA Weisungen;
- BAMF;
- LEA Berlin;
- Deutscher Bundestag;
- Bundesrat;
- BMI;
- BMAS;
- Bundesregierung.

### СМИ

В монитор также включены немецкие СМИ, например DW, rbb24, Tagesspiegel и Handelsblatt.

Состав источников может расширяться по мере развития проекта.

## Архив

Раздел **«Архив»** предназначен для работы с уже сохранёнными монитором публикациями.

Материалы можно фильтровать по году, источнику, BCA-релевантности, тематике, словам и фразам, а также сортировать по датам.

Архив рассчитан на материалы начиная с **2020 года**. Для исторических данных используется отдельная SQLite-база, поэтому весь архив не требуется держать в памяти интерфейса.

## Поиск

Можно выбрать готовую BCA-тему — например Jobcenter / Bürgergeld, безработица, § 24 AufenthG, Blue Card, гражданство или признание квалификаций.

Если нужной темы нет, используется **свободный запрос**. Так можно искать конкретный закон, параграф, ведомство, статус или ключевую фразу.

## Источники и статистика

Раздел **«Источники»** показывает по каждому источнику общее количество публикаций и распределение 🟢 / 🟡 / 🔴.

Статистика кликабельна: можно сразу перейти к соответствующим публикациям выбранного источника и уровня релевантности.

## Перевод через DeepL

В приложении предусмотрен перевод публикаций через **DeepL API**.

API-ключ можно вставить в поле в верхней части приложения. Ключ не должен публиковаться в GitHub.

## «БЫЛО ↔ СТАЛО»

В карточках публикаций есть экспериментальная функция сравнения доступных редакций. Результат зависит от наличия предыдущей версии в официальном источнике, локальной истории или доступном веб-архиве.

Функция находится в развитии и не влияет на основную работу монитора.

## Важно

Монитор помогает быстрее находить и сортировать потенциально значимые публикации, но не заменяет проверку первоисточника.

Для юридически значимой информации рекомендуется открывать оригинальную публикацию и проверять действующую редакцию документа на официальном ресурсе.

Количество найденных материалов зависит от доступности сайтов-источников и их текущей структуры.

## Запуск проекта локально

Требуется установленный Python.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## DeepL API при локальном запуске

При необходимости ключ можно сохранить в локальном `.env`:

```text
DEEPL_API_KEY=ваш_ключ
```

`.env` не должен загружаться в GitHub.

## Структура проекта

```text
BCA_Legal_Monitor/
├── app.py
├── requirements.txt
├── README.md
├── .gitignore
├── .env.example
├── collectors/
│   ├── official/
│   └── media/
├── processing/
├── legal_diff/
├── services/
├── storage/
└── data/
```

- `app.py` — интерфейс Streamlit;
- `collectors/` — получение публикаций из источников;
- `processing/` — обработка и классификация;
- `legal_diff/` — экспериментальное сравнение редакций;
- `services/` — вспомогательные сервисы;
- `storage/` и `data/` — архив и локальные данные;
- `requirements.txt` — зависимости Python.

## Назначение проекта

Проект создан как практический инструмент мониторинга информационного поля BCA: собрать значимые публикации в одном месте, уменьшить объём ручного просмотра сайтов и дать возможность быстро перейти от общей статистики к нужному первоисточнику.

**Принцип работы: источник → автоматическая фильтрация → проверка человеком.**
