# BCA Legal & Migration Monitor

**BCA Legal & Migration Monitor** — тестовое Streamlit-приложение для оперативного просмотра свежих публикаций, важных для работы BCA в сфере миграции, трудовой миграции и законодательства Германии.

🌐 **Онлайн-приложение:** https://bca-legal-migration-monitor.streamlit.app/

## Главная логика

Монитор отвечает на простой рабочий вопрос: **что нового появилось в нужных официальных источниках и СМИ за последние 48 часов?**

Основная выдача:

- объединяет официальные источники и СМИ в одну ленту;
- показывает только публикации с подтверждённой датой в пределах последних 48 часов;
- сортирует материалы от самых новых к более ранним;
- тематически отбирает публикации, связанные с направлениями BCA;
- не подменяет дату публикации датой обнаружения материала монитором;
- не показывает старые материалы как новые, даже если старая страница снова появилась в RSS или поисковой выдаче.

## Как пользоваться

### Свежая подборка

Это основной экран. Здесь находятся публикации за последние 48 часов. Можно смотреть общую ленту или выбрать конкретную группу/источник: официальные источники, СМИ, Gesetze im Internet, BA, BAMF, LEA Berlin, Bundestag и др.

### Поиск

Поиск работает **только внутри текущей свежей подборки за 48 часов**. Поэтому старые публикации 2015, 2020, 2024 и т. п. не должны появляться в результатах текущего мониторинга.

### Источники

Раздел показывает, из каких источников пришли свежие материалы и дату последней публикации в текущем 48-часовом окне.

## Источники

Среди официальных источников используются, в частности:

- Gesetze im Internet;
- Bundesagentur für Arbeit / BA Weisungen;
- BAMF;
- LEA Berlin;
- Deutscher Bundestag;
- Bundesrat;
- BMI;
- BMAS;
- Bundesregierung.

СМИ разделены на две группы:

- **крупные федеральные и общенациональные источники:** Tagesschau, ZDFheute, Deutschlandfunk, DW, SPIEGEL, ZEIT, Süddeutsche, FAZ, Handelsblatt, WELT и Tagesspiegel;
- **региональные источники:** WDR, NDR, BR24, SWR, MDR, rbb24, hessenschau (hr), Radio Bremen и SR.

Все они участвуют в той же общей свежей ленте. Отдельный источник показывается в фильтрах только тогда, когда от него есть материал в текущей подборке.

## Проверка дат

Дата — критическое поле для этого проекта. Для официальных страниц монитор старается получить дату самой публикации со страницы или из структурированных метаданных. Для RSS-источников используются только даты, помеченные коллектором как дата публикации.

Если достоверную дату определить не удалось, материал **не включается в свежую 48-часовую ленту**. Это сделано намеренно, чтобы старые публикации не выдавались за новые.

## Обновление

Обычное открытие приложения использует уже сохранённую свежую выборку и не запускает обход всех сайтов, поэтому интерфейс открывается быстро.

Кнопка **«Проверить сейчас»** запускает новый сбор, проверку дат, тематический отбор и обновление свежей ленты.

## Первоисточники и использование информации

Монитор предназначен для обнаружения и просмотра информации. Он показывает служебные данные о найденном материале и даёт переход на оригинальную публикацию. Для юридически значимой информации необходимо открывать первоисточник и проверять актуальный текст непосредственно на сайте владельца материала.

## Дополнительные функции

Перевод через DeepL и экспериментальное сравнение «БЫЛО ↔ СТАЛО» являются вспомогательными функциями и не влияют на основную логику свежего мониторинга.

## Запуск локально

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

API-ключ DeepL не должен публиковаться в GitHub. При необходимости его можно хранить локально в `.env`.

## Структура

```text
BCA_Legal_Monitor/
```

**Принцип работы:** источник → проверка даты → тематический отбор → единая свежая лента → переход к оригиналу.
